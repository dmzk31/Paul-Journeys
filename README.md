# 保羅的四次行程

製作：Daniel Kao

以《使徒行傳》和提供的參考簡報為基礎，製作繁體中文互動聖經地圖。

## 功能

- 四次行程、65個路線節點，保留回程重訪站次。
- 2D平面與3D地球投影切換，旋轉、縮放與傾斜視角。
- 逐站播放、暫停、進度拖曳、上一站／下一站、播放速度與視角跟隨。
- 左右箭頭會沿既有路線平滑前進或倒退，顯示目前移動路段；連按從當前位置接續，暫停可停在兩站之間。
- 各站事件摘要、經文出處、地點參考與書信著時說明。
- 每段同行者與分隊註記；區分經文明載、上下文接續、敘事推定及押送角色，提供86節可點開閱讀的經文。
- 電腦、手機及平板的響應式版面與觸控操作。
- 地圖優先版面：行程、站點事件、選站、播放設定與視角面板預設收起，按底部按鈕才開啟；選擇行程或站點後自動回到地圖。
- 網址記住行程、站次與顯示模式，例如 `#journey=4&stop=8&view=3d`。

純靜態 HTML、CSS、JavaScript，不需 API 金鑰、資料庫或建置工具。地圖程式庫、底圖和行程資料隨網站提供，瀏覽時不需向第三方地圖服務請求圖磚。瀏覽器須支援 WebGL。3D為地球投影，不含地形高程。

地圖上方「邊界」可切換依兩張主要參考圖校準的古代地區、現代國界、西元69年羅馬行省或關閉；詳見 SOURCES.md 的年代與授權說明。分區採不同底色，路線有白色襯線；保羅以紅色姓名標記與播放脈動外圈呈現，與城市點分開。

## 本機預覽

在本資料夾執行：

```sh
python -m http.server 8080
```

再開啟 http://localhost:8080 。請透過 HTTP 開啟，直接雙擊 `index.html` 會因瀏覽器的本機資料存取限制而無法讀取地圖。

## 部署至 GitHub Pages

1. 在 GitHub 建立儲存庫，例如 `paul-journeys`。
2. 將本資料夾的內容放在儲存庫根目錄，包含 `.github/workflows/pages.yml`。
3. 至儲存庫 **Settings → Pages → Build and deployment → Source**，選擇 **GitHub Actions**。
4. 推送至 `main` 只執行資料檢查，不會發布。日後確認要發布時，在 Actions 手動執行 **Validate atlas and publish manually**，並勾選 `publish`。
5. 部署成功後，在 Pages 或 Actions 查看實際網站網址。

所有網站資源都採相對路徑，可用於 `https://帳號.github.io/儲存庫名稱/` 的子目錄部署。若儲存庫預設分支不是 `main`，請同步修改 workflow 的分支設定。

也可不用 Actions，改以 **Deploy from a branch → main → / (root)** 發布靜態網站。

## 修改內容

- `assets/data/journeys.json`：四次行程、各站事件與座標，以及 `companionProfiles`（分段同行者）、`scriptureEvidence`（引用經文）；每站以 `companionProfile` 對應註記。
- `assets/app.js`：地圖、播放器與視角控制。
- `assets/style.css`：版面與配色。
- `index.html`：頁面結構。
- `SOURCES.md`：內容依據、資料授權與路線限制。

檢查資料：`python scripts/check.py`。發布檔案僅包含網站與地圖資源；原始參考文件保留在原資料夾。

## 操作

電腦：左鍵拖曳移動，滾輪縮放，3D模式右鍵拖曳旋轉與傾斜。手機：單指移動，雙指縮放與旋轉，3D模式雙指上下拖曳傾斜。也可開啟視角工具，以滑桿精確調整。按 N 恢復朝北；◎ 顯示地球全景。

底部「行程」切換四次行程，「站點」叫出本站事件及本段同行者的姓名、角色與經文根據，「選站」開啟獨立停靠站清單。「播放設定」提供進度、速度和視角跟隨；「視角」提供旋轉、傾斜與縮放。所有面板預設關閉，開啟後可按「關閉」回到地圖，選擇行程或站點亦會自動收起。主畫面保留小型播放與上一站／下一站按鈕，控制列位於地圖外。

點選地圖城市會叫出該站事件，點選路線則叫出該段事件與同行者。每站註記指前站抵達本站的一段；播放途中改為正在前往的一段。點人物下方的經文出處，或按「查閱本段經文」，即可閱讀所附《使徒行傳》的引文。「分隊、會合與其他相關人物」與確定同行名單分開呈現。

## 驗證範圍

地理來源核對與限制見 [GEOGRAPHY.md](./GEOGRAPHY.md)：47個地點與官方候選座標快照逐一比對；古代、現代邊界回查原始幾何。`coordinate-index.json` 保留座標核對基準，資料檢查會阻止無意的座標偏移。地區與島嶼代表點、候選遺址的限制也會顯示於站點內。

箭頭動畫已檢查前進、倒退、3D連按接續、中途暫停；觀察到兩站間的非整數進度及移動標記，並確認停止後保留中途位置。新版地圖集版面檢查320×568、390×700及電腦尺寸，沒有橫向溢出；初次載入與尺寸改變時，完整路線視野會重新適配。

本版已檢查桌面與390×844手機尺寸版面、四次行程切換、回訪站次、站點內容、播放／暫停、進度滑桿、2D／3D切換、地球全景、視角滑桿與資料來源對話框；檢查期間瀏覽器未記錄程式錯誤。路線資料完整性、相對資源路徑與JavaScript語法檢查通過。桌面上的手機尺寸模擬不能取代實機多指觸控測試。GitHub Pages的線上部署狀態另見下段。

同行者更新已驗證：庇哩亞至雅典的護送者與西拉／提摩太留守、馬可在別加離隊、播放途中顯示即將抵達路段的同行者、腓立比至特羅亞的分隊、亞朔步行路段，以及第四次航程的同行與押送角色。桌面與手機尺寸均可開啟經文引文，手機視窗沒有橫向溢出。線上發布須另以 GitHub Pages 的實際部署結果確認。

## 主要古代參考圖（2026-11-22）

使用者指定《保羅的行程》《新約時代的巴勒斯坦》為主要參考。預設「古代地區（參考圖）」包含42個地區／海域標籤及分色分界；原本69年行省保留為另一個對照選項。「巴勒斯坦詳圖」可一鍵放大第二張圖的範圍，顯示加利利海、死海、約旦河等水域與地理對照城市。兩圖為教學地圖，分界混合不同地域定義，不作精確測繪或同一年行政圖。
