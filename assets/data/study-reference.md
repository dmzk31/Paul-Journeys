# 保羅四次出外盡職的行程整理

**資料來源：**
1. 《使徒行傳生命讀經》──李常受
2. 《第九篇　保守自己在主工作的一道流中，為著召會的擴展，並且受主憐憫蒙拯救脫離撒但的詭計》
3. 《第十二篇　使徒行傳的繼續─基督團體的繼續》

以下依照三份資料，按**行程路線、主要事件、職事內容及結果**整理，不另外加入個人解釋或延伸觀點。

# 貳、第一次行程：從安提阿到居比路及小亞細亞

**經文：徒十三4～十四28**

### 一、行程路線

安提阿 → 西流基 → 居比路（撒拉米、帕弗）→ 旁非利亞的別加 → 彼西底的安提阿 → 以哥念 → 路司得 → 特庇 → 路司得 → 以哥念 → 彼西底的安提阿 → 旁非利亞的別加 → 亞大利 → 安提阿。

### 二、主要事件

| 地點 | 主要事件 | 經文 |
|---|---|---|
| 安提阿 | 五位申言者和教師事奉主並禁食，聖靈分別巴拿巴和掃羅，差遣他們出去 | 十三1～4 |
| 居比路 | 在撒拉米的猶太會堂宣傳神的話 | 十三4～5 |
| 帕弗 | 遇見行法術的以呂馬；保羅被聖靈充溢，責備以呂馬；省長士求保羅相信 | 十三6～12 |
| 旁非利亞的別加 | 約翰馬可離開他們，回耶路撒冷去 | 十三13 |
| 彼西底的安提阿 | 保羅在會堂傳講基督的死與復活；猶太人抵擋，保羅和巴拿巴轉向外邦人 | 十三14～52 |
| 以哥念 | 許多猶太人和希利尼人相信；使徒放膽講論主恩典的話 | 十四1～7 |
| 路司得 | 保羅醫治生來瘸腿的人；群眾想向使徒獻祭；保羅遭石頭打，被拖出城外 | 十四8～20 |
| 特庇 | 傳福音，使好些人作了門徒 | 十四20～21 |
| 回訪各城 | 堅固門徒的魂，勸勉他們恆守信仰；在各召會中選立長老 | 十四21～23 |
| 安提阿 | 聚集召會，述說神同著他們所行的一切事，以及神如何為外邦人開了信的門 | 十四26～28 |

### 三、這次行程的主要內容

**1. 從安提阿開始，將國度的福音開展到外邦世界。**

《使徒行傳生命讀經》第三十六篇指出，這是主將國度的福音開展到外邦世界所採取的一大步。

這行動不是藉著人的組織、計畫或募集基金，乃是藉著基督身體上的肢體，事奉主並禁食，與元首配合而有的。[生命讀經](https://line.twgbr.org/life-study/44_36.html)

**2. 在各地傳講基督，建立地方召會。**

《第九篇》指出：

「在使徒保羅第一次擴展福音的行程中，他到了居比路，然後到小亞細亞，設立了好幾個地方召會。」

**3. 回訪並堅固門徒，在各召會中選立長老。**

保羅和巴拿巴回訪路司得、以哥念及彼西底的安提阿，堅固門徒，勸勉他們恆守信仰，並在各召會中選立長老。

**4. 回到安提阿，交通神在福音擴展上的行動。**

《使徒行傳生命讀經》第四十篇指出，這次聚集不是為著報告任務，乃是為著交通神在祂福音開展上的行動。[生命讀經](https://line.twgbr.org/life-study/44_40.html)

# 參、第二次行程：福音從小亞細亞擴展到歐洲

**經文：徒十五40～十八22**

### 一、行程路線

安提阿 → 敘利亞 → 基利家 → 特庇 → 路司得 → 弗呂家、加拉太地區 → 每西亞 → 特羅亞 → 撒摩特喇 → 尼亞波利 → 腓立比 → 帖撒羅尼迦 → 庇哩亞 → 雅典 → 哥林多 → 堅革哩 → 以弗所 → 該撒利亞 → 耶路撒冷 → 安提阿。

### 二、主要事件

| 地點 | 主要事件 | 經文 |
|---|---|---|
| 安提阿 | 保羅與巴拿巴因馬可起爭執而分開；保羅揀選西拉同行 | 十五35～40 |
| 敘利亞、基利家 | 走遍各地，堅固眾召會 | 十五40～41 |
| 特庇、路司得 | 保羅帶提摩太一同出去；眾召會在信仰上得堅固，人數天天加增 | 十六1～5 |
| 弗呂家、加拉太地區 | 聖靈禁止他們在亞西亞講道 | 十六6 |
| 每西亞 | 耶穌的靈不許他們往庇推尼去 | 十六7 |
| 特羅亞 | 保羅夜間看見馬其頓人的異象，於是往馬其頓去 | 十六8～10 |
| 腓立比 | 呂底亞一家得救；保羅和西拉被囚；禁卒和全家得救 | 十六11～40 |

| 庇哩亞 | 當地人熱切領受神的話，天天考查聖經 | 十七10～13 |

### 三、這次行程的主要內容

**1. 保羅與巴拿巴分開，開始第二次出外盡職。**

《使徒行傳生命讀經》第四十三篇指出，保羅揀選西拉，蒙弟兄們把他交與主的恩典，開始第二次行程。

保羅也在這次行程中帶提摩太一同出去。[生命讀經](https://line.twgbr.org/life-study/44_43.html)

**2. 藉著聖靈的禁止、耶穌之靈的不許，以及馬其頓人的異象，福音轉向歐洲。**

《使徒行傳生命讀經》第四十五篇指出，這是主行動的主要一步，將祂的國開展到另一大陸，就是歐洲。

路加也是從特羅亞開始加入保羅盡職的旅程。[生命讀經](https://line.twgbr.org/life-study/44_45.html)

**3. 在歐洲興起並建立地方召會。**

保羅先後到了腓立比、帖撒羅尼迦、庇哩亞、雅典和哥林多。

在腓立比，呂底亞一家及禁卒一家得救；在哥林多，保羅住了一年零六個月，教導神的話。

**4. 保羅傳講基督，並照著聽眾的情形說話。**

在帖撒羅尼迦，保羅本著聖經陳明基督必須受害並復活。

在雅典，他對敬拜偶像及崇尚哲學的人，從神的創造開始傳講。[生命讀經](https://line.twgbr.org/life-study/44_46.html)

**5. 回到安提阿，結束第二次行程。**

保羅經過以弗所、該撒利亞，上耶路撒冷問候召會，然後回到安提阿。

《使徒行傳生命讀經》第四十八篇指出，保羅這樣訪問耶路撒冷召會，是要盡力保守基督身體的一。[生命讀經](https://line.twgbr.org/life-study/44_48.html)

# 肆、第三次行程：堅固眾門徒，並加強各地召會的建造

**經文：徒十八23～二一17**

### 一、行程路線

安提阿 → 加拉太 → 弗呂家 → 以弗所 → 馬其頓 → 希臘 → 馬其頓 → 特羅亞 → 米利都 → 哥士 → 羅底 → 帕大喇 → 推羅 → 多利買 → 該撒利亞 → 耶路撒冷。

### 二、主要事件

| 地點 | 主要事件 | 經文 |
|---|---|---|

| 加拉太、弗呂家 | 挨次經過各地，堅固眾門徒 | 十八23 |
| 以弗所 | 遇見只受過約翰之浸的門徒，使他們受浸歸入主耶穌的名 | 十九1～7 |

| 以弗所 | 神藉保羅行異能；主的話強有力地擴長，且得勝 | 十九11～20 |
| 以弗所 | 保羅靈裡定意，經過馬其頓、亞該亞，往耶路撒冷去，之後也要去羅馬 | 十九21～22 |

| 馬其頓、希臘 | 保羅勸勉門徒，在希臘住了三個月；因猶太人設計要害他，改經馬其頓返回 | 二十1～3 |
| 特羅亞 | 與聖徒聚集擘餅，講論到深夜；猶推古從樓上掉下，後來活過來 | 二十4～12 |

### 三、這次行程的主要內容

**1. 堅固眾門徒，並在以弗所長時間盡職。**

保羅第三次行程從安提阿出發，經過加拉太和弗呂家，堅固眾門徒。

《使徒行傳生命讀經》第五十篇指出，保羅這次再到以弗所，在那裡停留了三年。[生命讀經](https://line.twgbr.org/life-study/44_50.html)

**2. 在以弗所傳講神國，並使主的話擴長。**

保羅在以弗所的職事，使亞西亞的居民聽見主的話。

這次職事也引起以弗所的大擾亂。[生命讀經](https://line.twgbr.org/life-study/44_52.html)

**3. 保羅關切各地召會，也關切耶路撒冷的聖徒。**

《使徒行傳生命讀經》第五十二篇指出，保羅有四重負擔：

- 為哥林多召會的負擔。
- 為以弗所召會的負擔。
- 為耶路撒冷光景的負擔。
- 為羅馬召會的負擔。

保羅在這次行程中，也有負擔顧到耶路撒冷貧乏聖徒的需要。[生命讀經](https://line.twgbr.org/life-study/44_52.html)

**4. 在米利都囑咐以弗所召會的長老。**

保羅向長老們述說自己如何服事主，並囑咐他們留意自己和全群，牧養神的召會。

他指出自己在以弗所三年之久，晝夜不住地流淚勸戒聖徒；凡與聖徒有益的，或在公眾面前，或挨家挨戶，他都教導他們。[生命讀經](https://line.twgbr.org/life-study/44_53.html)

**5. 雖然多次受到警告，仍前往耶路撒冷。**

在推羅，門徒藉著那靈告訴保羅不要上耶路撒冷。

在該撒利亞，亞迦布預告他將被捆綁，弟兄們也苦勸他不要去。

但保羅沒有接受勸告，仍然前往耶路撒冷。

《第九篇》與《使徒行傳生命讀經》第五十六篇均指出，這事涉及保羅對基督身體說話的接受與順從。 [生命讀經](https://line.twgbr.org/life-study/44_56.html)

# 伍、第四次行程：從該撒利亞到羅馬

**經文：徒二七1～二八31**

### 一、行程路線

該撒利亞 → 西頓 → 居比路背風岸 → 基利家、旁非利亞一帶 → 每拉 → 革尼土附近 → 革哩底島（佳澳）→ 海上遇狂風 → 米利大島 → 敘拉古 → 利基翁 → 部丟利 → 亞比烏市 → 三館 → 羅馬。

### 二、行程背景

這次行程與前三次不同。

《第九篇》指出，保羅第四次的行程不是他自願發起的，而是作為羅馬帝國的囚犯，被帶到羅馬。

在此以前，保羅因猶太人的控告被拘留，並利用羅馬公民的身分，上訴於該撒，使自己脫離逼迫他的人，得以完成盡職的路程。

保羅在該撒利亞被扣留監管兩年，之後被送往羅馬。第九篇　保守自己在主工作的一道流中，为着召会的扩展，并且受主怜…

### 四、這次行程的主要內容

**1. 主在航程中的主宰看顧。**

《使徒行傳生命讀經》第七十篇指出，在這次航程中可以看見：

- 撒但對使徒的攻擊。
- 主的主宰看顧。
- 保羅的生活、行為和品格。

保羅雖然是受監禁的囚犯，卻在艱苦、不順的航程中過著超越、尊貴且滿有智慧的生活。[生命讀經](https://line.twgbr.org/life-study/44_70.html)

**2. 保羅成為同船之人的生命保證人和安慰者。**

在風暴中，神藉著使者告訴保羅，他必站在該撒面前，而同船的人神也都賜給他了。

保羅勸勉眾人放心振作，表明他相信神所說的話必定成就。

**3. 在米利大島彰顯基督。**

保羅雖然被毒蛇纏住，卻沒有受傷。

他又禱告、按手醫治部百流的父親，後來島上的其他病人也來得了醫治。

《使徒行傳生命讀經》第七十一篇指出：

在風暴的海上，保羅成為同船之人的主人、生命的保證人和安慰者；在平安的陸地上，他成為當地人的醫治者和喜樂。[生命讀經](https://line.twgbr.org/life-study/44_71.html)

**4. 保羅在航程中活基督，顯大基督。**

《第十二篇》特別指出：

保羅第四次盡職的行程，給我們看見他的生活，就是活基督、顯大基督，在基督裡作一切事，並竭力追求基督，好給人看出他是在基督裡。

在漫長、不幸且受監禁的航程中，他活出全然尊貴的生活，具有最高標準的人性美德，彰顯最高超的神聖屬性。

**5. 在羅馬享受身體生活，並繼續盡職。**

保羅受到部丟利弟兄們愛心的關切，以及羅馬弟兄們熱烈的歡迎。

《使徒行傳生命讀經》第七十一篇和《第十二篇》都指出，這顯出早期召會和使徒之間美麗的身體生活。

保羅到了羅馬，雖然仍受監管，卻在自己所租的房子住了兩年，放膽宣揚神的國，教導主耶穌基督的事，毫無阻礙。[生命讀經](https://line.twgbr.org/life-study/44_71.html) 第十二篇　使徒行传的继续─基督团体的继续

## 柒、三份資料對四次行程的著重

依照原資料，可整理為以下四個方面：

| 行程 | 資料中的著重 |
|---|---|
| **第一次** | 藉著基督身體上肢體的配合，將國度的福音開展到外邦世界，並建立地方召會。 |
| **第二次** | 在那靈的引導下，福音從小亞細亞擴展到歐洲，並在各地興起召會。 |
| **第三次** | 堅固、教導並牧養眾召會；保羅關切基督的身體，也在前往耶路撒冷的事上面對身體的勸告。 |
| **第四次** | 在監禁、風暴和艱難環境中活基督、顯大基督，並藉著身體的交通得著安慰與鼓勵，直到羅馬繼續盡職。 |
